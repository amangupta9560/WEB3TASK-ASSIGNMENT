# 📸 Application Screenshots Guide

This directory holds the interface screenshots for the YouTube Watch Party system (`SyncParty`).
Please capture high-resolution screenshots from your live browser session (`http://localhost:5173` or deployed production URL) and save them under the exact filenames below:

| File Name | View Description | Suggested Capture Method |
|---|---|---|
| `01-home-page.png` | Landing page hero, action cards, active party rooms | Desktop browser at 1920x1080 |
| `02-create-room.png` | "Create Watch Party" form filled with title & video URL | Desktop modal / home view |
| `03-host-controls-view.png` | Host watching party with enabled playback controls & amber 👑 badge | Host session viewport |
| `04-participant-restricted-view.png` | Participant watching party with locked controls & permission toast | Incognito tab as joiner |
| `05-role-assignment-menu.png` | Host clicking participant options menu (Make Moderator / Kick / Transfer) | Host session dropdown |
| `06-participant-list-badges.png` | Participant list displaying Host, Moderator, and Participant badges | Sidebar in WatchRoom |
| `07-change-video-modal.png` | "Change Video" modal open with input field | In-room modal |
| `08-live-chat-reactions.png` | Live chat message stream with floating emoji reactions | In-room chat sidebar |
| `09-mobile-responsive-view.png` | Mobile responsive theater view with tab switching (Player/Chat/Users) | DevTools iPhone/Pixel view |
